# 수도권 단지 시세 지도

주소를 검색하거나 지도를 누르면 카카오맵 위에 반경 안 단지가 **평형·가격 핀**으로 뜨고, 단지를 누르면 최근 실거래(면적별 중위가, 월별 추이, 거래 내역)를 볼 수 있는 사이트입니다.
아파트와 오피스텔을 따로 보고, 분양권·입주권 실거래, 청약홈 분양정보, 모집공고 분석 요약, 시장조사 PPT(기초자료·상세자료)까지 한 화면에서 다룹니다.
**토지**(최근 5년, 지목별)와 **상가·업무**(상업업무용, 최근 3년, 건물주용도·일반/집합별)도 볼 수 있습니다. 이 둘은 국토부가 지번을 일부만 공개해(예: 1**) 필지가 아니라 **법정동 단위로 모아서** 보여 줍니다.

## 동작 방식

- **서버가 없습니다.** GitHub Pages에 올린 정적 사이트이고, 사이트를 연 **브라우저가 공공데이터 API를 직접 조회**합니다.
- **국토부 인증키**는 사이트 왼쪽 입력칸에 한 번 넣으면 그 브라우저에만 저장됩니다(저장소·사이트에는 올라가지 않음).
- **저장본(캐시)**: 한 번 조회한 자료는 그 브라우저의 IndexedDB에 저장해 다음에 다시 받지 않습니다.

  | 자료 | 다시 받는 시점 |
  |---|---|
  | 실거래(아파트·오피스텔·분양권·토지·상가), 이번 달·지난달 | 매번 새로 조회 (신고 기한 30일·해제 신고 반영) |
  | 실거래, 2~3개월 전 | 저장 후 7일 |
  | 실거래, 그 이전 | 저장 후 30일 |
  | 세대수·준공연도·층수(K-apt·건축물대장) | 찾은 값 180일, 못 찾은 지번 30일 |
  | 주소 → 좌표 | 180일 |

  예전 버전이 localStorage에 저장한 자료(`bld_v4`, `geo_v1`)는 처음 열 때 자동으로 옮기고 지웁니다.

## 저장소 구성

| 위치 | 역할 |

| `site/data/notices/` | 모집공고 분석 결과 (요약 JSON + PPT). `index.json`에 목록 |
| `scripts/build_notice_ppt.py` | 모집공고 분석 PPT(사보이 양식) 생성 — Claude가 분석할 때 사용 |

`site/app.js`는 자동 생성 파일이라 저장소에 올리지 않습니다(`.gitignore`). **코드를 고칠 때는 `src/`를 고치세요.**

## 처음 설정 (한 번만)

1. 저장소 **Settings > Pages > Build and deployment > Source**를 **GitHub Actions**로 둡니다.
2. **Settings > Secrets and variables > Actions > Variables**에 `KAKAO_JS_KEY`(카카오 **JavaScript 키**)를 등록합니다.
3. 카카오 디벨로퍼스 > 내 애플리케이션 > 플랫폼 > Web > 사이트 도메인에 `https://igas3005.github.io`를 추가합니다.
4. `main`에 올라가면 자동 배포됩니다. 수동 배포는 Actions 탭 > 「사이트 배포」 > Run workflow.

공공데이터포털에서 쓰는 API(활용신청 필요): 아파트 매매 실거래가(상세), 오피스텔 매매 실거래가, 토지 매매 실거래가, 상업업무용 부동산 매매 실거래가, 분양권전매 실거래가, 건축HUB 건축물대장, 공동주택 단지 목록·기본 정보, 청약홈 분양정보·경쟁률, 행정안전부 주민등록 인구·세대 / 성·연령별 인구.

## 자주 막히는 곳

- **지도가 안 뜸**: `KAKAO_JS_KEY` 변수 이름(Variables 탭), 카카오 사이트 도메인 등록, 키 종류(JavaScript 키)를 확인하세요.
- **"인증키 오류"**: 공공데이터포털에서 해당 API 활용신청이 승인됐는지 확인하세요. 승인 직후에는 반영에 시간이 걸릴 수 있습니다.
- **HTTP 429**: 짧은 시간에 요청이 몰린 경우입니다. 잠시 뒤 다시 검색하세요. 계속되면 그날 호출 한도를 넘은 것일 수 있습니다.
- **어떤 단지에 "거래 없음"**: 그 기간에 거래가 없거나, 신고된 단지명·지번이 단지 목록과 달라 연결되지 않은 경우입니다.
- **최신 자료가 안 보이는 것 같을 때**: 이번 달·지난달은 매번 새로 받습니다. 그 이전 달을 강제로 다시 받으려면 브라우저 사이트 데이터를 지우면 됩니다(인증키도 다시 넣어야 함).

## 알아둘 점

- 화면의 평형은 공급면적 추정치(전용 × 1.32)입니다. PPT의 평당가는 K-apt 공급/전용 비율이 있으면 그 값을, 없으면 1.32를 씁니다.
- 해제(취소)된 거래는 뺍니다. 최근 두 달은 신고 기한 때문에 거래 수가 더 늘어날 수 있습니다.
- 단지 목록(`complexes.json`)에 없는 단지(신축 등)는 지도에 나오지 않습니다. 입주 전 단지는 분양권·입주권 거래로만 보입니다.
- 사이트 주소를 아는 사람은 누구나 열 수 있습니다. 시세와 단지 정보는 모두 공개 자료이고, 인증키가 없으면 시세는 나오지 않습니다.
- 토지·상가 평당가: 토지는 거래면적, 집합(구분상가)은 건물(전용)면적, 일반(통건물)은 대지면적 기준입니다. 지분거래는 단가를 왜곡해 기본으로 뺍니다(토지는 포함 선택 가능).
- 참고용이며 투자 판단의 근거가 아닙니다.
