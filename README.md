# 수도권 단지 시세 지도

주소를 검색하면 카카오맵 위에 반경 내 아파트 단지가 **평형·가격 핀**으로 표시되고, 단지를 누르면 최근 실거래(면적별 중위가, 월별 추이, 거래 내역)를 볼 수 있는 사이트입니다.
국토교통부 실거래가는 GitHub가 매일 자동으로 받아서 갱신합니다. 내 PC에 파이썬을 설치할 필요가 없습니다.

## 구성

| 위치 | 역할 |
|---|---|
| `site/` | 사이트 본체 (지도 화면) |
| `site/data/complexes.json` | 단지 9,775개의 이름·주소·좌표 |
| `scripts/collect.py` | 국토부 API에서 실거래를 받아 단지별 JSON으로 정리 |
| `.github/workflows/deploy.yml` | 매일 04:30(KST)에 수집 → 사이트 배포. Actions 탭에서 수동 실행도 가능 |

## 설정 순서 (처음 한 번)

1. **저장소 만들기**: GitHub에서 새 저장소(Repository)를 만듭니다. 무료 계정은 GitHub Pages를 쓰려면 **Public** 이어야 합니다.
2. **파일 올리기**: 이 압축 파일을 풀고, 안의 내용 전체(`.github` 폴더 포함)를 저장소에 올립니다. (저장소 화면 > Add file > Upload files에 폴더째 끌어다 놓기. `.github` 폴더가 보이지 않으면 숨김 폴더 표시를 켜세요.)
3. **Pages 켜기**: 저장소 Settings > Pages > Build and deployment > Source를 **GitHub Actions** 로 선택합니다.
4. **키 등록**: 저장소 Settings > Secrets and variables > Actions
   - **Secrets** 탭에서 New repository secret: 이름 `DATA_GO_KR_KEY`, 값은 공공데이터포털 인증키
   - **Variables** 탭에서 New repository variable: 이름 `KAKAO_JS_KEY`, 값은 카카오 JavaScript 키
5. **카카오 사이트 도메인 등록**: 카카오 디벨로퍼스 > 내 애플리케이션 > 앱 설정 > 플랫폼 > Web > 사이트 도메인에 `https://<내 GitHub 아이디>.github.io` 를 추가합니다. (등록하지 않으면 지도가 뜨지 않습니다.)
6. **첫 실행**: 저장소의 Actions 탭 > 「시세 수집 및 사이트 배포」 > Run workflow. 수집에 보통 10~30분 걸립니다.
7. 끝나면 `https://<내 GitHub 아이디>.github.io/<저장소 이름>/` 에서 사이트가 열립니다. 이후에는 매일 자동으로 갱신됩니다.

## 자주 막히는 곳

- **지도가 안 뜸**: 4번의 `KAKAO_JS_KEY` 변수 이름(Variables 탭), 5번의 도메인 등록을 확인하세요. 키는 「JavaScript 키」여야 합니다(REST API 키 아님).
- **"시세 데이터가 아직 없어요"**: 수집이 실패한 경우입니다. Actions 탭에서 실행 기록의 「실거래 수집」 단계 로그를 열어 보세요.
  - `SERVICE_KEY_IS_NOT_REGISTERED_ERROR`: 공공데이터포털에서 「국토교통부_아파트 매매 실거래가 상세 자료」 또는 「아파트 매매 실거래 자료」에 활용신청이 되어 있는지 확인하세요. (둘 중 하나만 되어 있어도 자동으로 맞는 쪽을 씁니다. 승인 직후에는 반영에 시간이 걸릴 수 있습니다.)
  - 요청 한도 초과: 하루가 지난 뒤 다시 실행하세요.
- **어떤 단지에 "거래 없음"**: 최근 기간에 거래가 없거나, 신고된 단지명·지번이 목록과 달라 연결되지 않은 경우입니다. 수집 로그 끝에 「매칭 안 된 상위 단지」 목록이 나오니 참고하세요.

## 설정 바꾸기

- 수집 기간: `.github/workflows/deploy.yml` 의 `MONTHS`(기본 12개월). 늘리면 요청 수도 늘어납니다.
- 수집 시각: 같은 파일의 `cron`.

## 알아둘 점

- 평형은 전용면적 기준 추정치입니다(공급면적 ≈ 전용 × 1.32). 실거래 자료에는 공급면적이 없습니다.
- 해제(취소)된 거래는 제외합니다. 최근 두 달은 신고 기한(계약 후 30일) 때문에 거래 수가 더 늘어날 수 있습니다.
- 단지 목록에 없는 단지(신축 등)는 지도에 나타나지 않습니다.
- 사이트 주소를 아는 사람은 누구나 열 수 있습니다. 시세와 단지 정보는 모두 공개 자료입니다.
- 참고용이며 투자 판단의 근거가 아닙니다.
